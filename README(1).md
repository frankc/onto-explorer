# drC's Onto-Explorer

Browse twelve standard RDF vocabularies (schema.org, FOAF, ORG, SKOS, Dublin Core, PROV-O,
OWL-Time, GeoSPARQL, DCAT, ODRL, QUDT, SIOC) against a sample or your own app description,
compare overlapping terms, and collect your picks to take into Onto20Q
(https://codesupreme.ai/ontologies).

A single static page: no server, no API key, no AI calls. Everything runs in the browser.

Live at https://onto-explorer.codesupreme.ai
